# PRYECTO-PPI

Repositorio del Proyecto Pedagógico Integrador de grado 11 para **RECORDATE**, sistema de recordatorio de actividades académicas de la IE La Candelaria.

## Aplicación principal

La aplicación que debe ejecutarse para probar RECORDATE está en [`ppi-react`](ppi-react/). Incluye landing, autenticación Supabase opcional, acceso DEMO, dashboard, gestión de tareas, calendario, recordatorios, prioridades, modo enfoque, compartir agendas, chat, perfil y configuración.

```bash
cd ppi-react
npm install
npm run dev
```
